Panduan Registrasi dan Mendapatkan Token Fonnte WhatsApp Gateway
Langkah 1 — Registrasi Akun Fonnte
  1. Buka website fonnte.com.
  2. Klik tombol Register.
  3. Lengkapi formulir pendaftaran dengan data berikut:
    • Nama Lengkap: Masukkan nama lengkap Anda.
    • Email: Gunakan alamat email yang aktif.
    • Password: Buat password yang aman dan mudah diingat.
    • Nomor WhatsApp: Masukkan nomor WhatsApp yang aktif.
  4. Klik tombol Register untuk membuat akun.
  5. Lakukan verifikasi email apabila diminta.
  6. Setelah akun berhasil dibuat, login ke dashboard Fonnte menggunakan email dan password yang telah didaftarkan.
Langkah 2 — Menambahkan Device WhatsApp
  1. Setelah berhasil login, buka menu Device pada dashboard Fonnte.
  2. Klik tombol Add Device.
  3. Lengkapi data perangkat:
    • Device Name: Nama perangkat yang akan digunakan, misalnya: WhatsApp Sekolah, WA Absensi, WA Notifikasi.
    • Device Number: Nomor identitas perangkat sebagai penanda (bebas diisi sesuai kebutuhan).
  4. Klik Add Device untuk menyimpan perangkat.
Langkah 3 — Menghubungkan WhatsApp
  1. Pada daftar perangkat yang telah dibuat, klik tombol Connect.
  2. Sistem akan menampilkan QR Code.
  3. Buka aplikasi WhatsApp pada ponsel yang akan digunakan.
  4. Pilih menu:
    • Android: Menu (⋮) → Perangkat Tertaut → Tautkan Perangkat.
    • iPhone: Pengaturan → Perangkat Tertaut → Tautkan Perangkat.
  5. Scan QR Code yang muncul pada dashboard Fonnte menggunakan WhatsApp.
  6. Tunggu hingga status perangkat berubah menjadi Connected.
Langkah 4 — Mendapatkan Token API
  1. Pastikan status perangkat sudah Connected.
  2. Pada perangkat yang telah terhubung, klik tombol Token.
  3. Fonnte akan menampilkan Token API yang digunakan untuk menghubungkan aplikasi dengan layanan Fonnte.
  4. Salin token tersebut dan simpan dengan baik.
Contoh token: M@N!4Yr-Vs#CPtaopCkE
Langkah 5 — Mengisi Token pada Aplikasi
  1. Kembali ke halaman pengaturan WhatsApp Gateway pada aplikasi ini.
  2. Tempelkan Token API yang telah disalin ke kolom Token API.
  3. Klik tombol Simpan untuk menyimpan konfigurasi.
  4. Setelah tersimpan, aplikasi siap digunakan untuk mengirim notifikasi WhatsApp secara otomatis.
Cara Memastikan Konfigurasi Berhasil
  • Token berhasil tersimpan tanpa muncul pesan error.
  • Status perangkat pada dashboard Fonnte masih Connected.
  • Fitur pengiriman WhatsApp pada aplikasi dapat mengirim pesan dengan sukses.
  • Pesan percobaan berhasil diterima pada nomor tujuan.
Catatan Penting
  • Nomor WhatsApp yang digunakan harus tetap aktif dan terhubung ke internet.
  • Jangan membagikan Token API kepada pihak lain.
  • Jika WhatsApp logout atau perangkat terputus, lakukan scan QR Code kembali.
  • Jika token tidak dapat digunakan, buat token baru melalui dashboard Fonnte.
  • Disarankan menggunakan nomor WhatsApp khusus untuk kebutuhan sistem agar pengiriman notifikasi lebih stabil.
Tips
Gunakan nomor WhatsApp yang selalu aktif dan jarang digunakan untuk aktivitas pribadi agar layanan notifikasi sekolah, absensi, dan informasi penting lainnya dapat berjalan tanpa gangguan.
